# NEW HAUZ - README DEL PROYECTO

## Descripción General

Plataforma inmobiliaria integral para comercialización de inmuebles, arquitectura, construcción e inversión inmobiliaria en el Estado de Querétaro, México.

## Arquitectura Tecnológica

- Laravel 13.x
- Filament v3
- Livewire v3
- Blade
- Tailwind CSS v4
- PostgreSQL 16
- PostGIS
- Spatie Permission
- Spatie Media Library
- Docker
- Nginx
- Cloudflare
