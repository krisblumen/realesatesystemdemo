Small uppercase pill for property operation type, commercial status and zone tags.

```jsx
<Badge variant="orange" solid>Venta</Badge>
<Badge variant="navy">Preventa</Badge>
<Badge variant="success">Disponible</Badge>
```

Variants: `neutral`, `navy`, `orange`, `success`, `warning`, `danger`. `solid` swaps the soft tint for a filled chip (use on photography). Montserrat 600, 12px tracked.
