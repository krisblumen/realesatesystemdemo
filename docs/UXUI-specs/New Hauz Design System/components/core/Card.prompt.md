Generic surface card — 16px radius, soft shadow, hover elevation. Base building block for service tiles, panels and dark premium sections.

```jsx
<Card><h3>Arquitectura</h3><p>Diseño y planeación.</p></Card>
<Card dark>Invertimos donde otros ven terrenos.</Card>
```

Props: `hover` (default true), `padding` (px), `dark` (navy premium surface).
