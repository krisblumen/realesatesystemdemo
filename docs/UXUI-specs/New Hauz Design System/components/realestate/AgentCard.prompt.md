Agent / asesor contact card — photo (or navy initials), name, role, assigned zone, and WhatsApp (green) + phone CTAs. WhatsApp is the priority conversion per the PRD.

```jsx
<AgentCard name="Kristian Álvarez" role="Asesor Senior" zone="Juriquilla · Zibatá" />
```

Lives in the property-detail sticky panel and the "Agentes por Zona" grid.
