# RFC-038 Dashboard Comercial

## Objetivo
Implementar un dashboard ejecutivo para monitorear la operación comercial.

## Responsable
Edgar

## KPIs
- Leads generados
- Leads por agente
- Leads por zona
- Inmuebles activos
- Inmuebles vendidos
- Conversión

## Widgets
- Resumen general
- Gráficas
- Tendencias

## Definition of Done
Dashboard funcional en Filament.
