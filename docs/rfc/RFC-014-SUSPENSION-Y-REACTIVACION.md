# RFC-014 Suspensión y Reactivación

## Objetivo
Permitir controlar acceso de usuarios.

## Responsable
Edgar

## Funcionalidad
- Suspender usuario
- Reactivar usuario
- Registrar fecha
- Registrar responsable

## Reglas
- Agentes suspendidos no pueden ingresar.
- Admin no puede suspender Owner.

## QA
Validar intentos de acceso.

## Definition of Done
Control completo de suspensión operando correctamente.
