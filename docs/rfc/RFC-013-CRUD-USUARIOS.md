# RFC-013 CRUD Usuarios

## Objetivo
Permitir administración de usuarios desde Filament.

## Responsable
Edgar

## Alcance
- Crear usuarios
- Editar usuarios
- Consultar usuarios
- Filtros
- Búsquedas

## UI
Filament Resource UserResource

## Validaciones
- Email único
- Campos obligatorios

## Definition of Done
CRUD operativo desde panel administrativo.
