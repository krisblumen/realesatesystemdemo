# RFC-021 Características Dinámicas

## Objetivo
Permitir atributos flexibles para distintos tipos de inmuebles.

## Responsable
Kristian

## Alcance
- Características configurables
- Campos dinámicos
- Catálogos

## Ejemplos
- Alberca
- Jardín
- Roof Garden
- Seguridad

## Definition of Done
Características configurables y persistentes.
