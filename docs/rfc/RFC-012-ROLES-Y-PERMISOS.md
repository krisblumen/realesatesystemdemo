# RFC-012 Roles y Permisos

## Objetivo
Implementar control de acceso basado en roles.

## Responsable
Edgar

## Roles Iniciales
- Owner
- Admin
- Agente

## Permisos Base
- Gestionar usuarios
- Gestionar inmuebles
- Gestionar leads
- Gestionar zonas

## Reglas
Owner tiene control total.

## Definition of Done
Roles operativos mediante Spatie Permission.
