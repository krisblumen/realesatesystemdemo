# RFC-017 Asignación de Agentes

## Objetivo
Permitir asignar agentes inmobiliarios a zonas específicas.

## Responsable
Kristian

## Alcance
- Asignar agente
- Reasignar agente
- Consultar asignaciones

## Reglas
- Un agente puede pertenecer a varias zonas.
- Una zona puede tener múltiples agentes.

## QA
Validar permisos y relaciones.

## Definition of Done
Asignaciones funcionando correctamente.
