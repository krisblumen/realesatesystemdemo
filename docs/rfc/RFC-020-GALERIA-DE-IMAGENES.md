# RFC-020 Galería de Imágenes

## Objetivo
Gestionar fotografías de inmuebles mediante Media Library.

## Responsable
Kristian

## Alcance
- Imagen principal
- Galería múltiple
- Orden de imágenes
- Eliminación

## Reglas
- Múltiples imágenes por inmueble
- Imagen principal obligatoria

## Definition of Done
Galería funcional desde Filament.
