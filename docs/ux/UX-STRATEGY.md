# UX Strategy

## Objetivo Principal

Maximizar la generación de leads inmobiliarios.

## Objetivos UX

- Reducir fricción.
- Facilitar contacto.
- Facilitar búsqueda.
- Generar confianza.
- Mejorar conversión.

## Usuarios Objetivo

### Compradores

Buscan inmuebles.

### Propietarios

Buscan vender o rentar.

### Inversionistas

Buscan oportunidades.

### Desarrolladores

Buscan comercialización.

## KPIs

- Leads generados.
- CTR WhatsApp.
- Tiempo en sitio.
- Conversión de formularios.
